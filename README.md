## Featured Projects

1. **Lumeria — AI-Powered Tourism Ecosystem** *(Google Play & YouTube Demo)*
   - Full-stack mobile tourism platform featuring Arabic RAG chatbots, multi-model recommendations, 3D visualization, interactive location services, and Supabase cloud sync.
2. **RAG-Powered Arabic Tourism Chatbot** *(Drive Demo)*
   - Low-latency contextual retrieval system built with LangChain, Gemini API, and FAISS vector search, deployed on Hugging Face Spaces via FastAPI.
3. **Driver Drowsiness Detection System** *(GitHub Repository)*
   - Hybrid spatio-temporal deep learning network (CNN + Bi-LSTM) evaluated over 41,000+ sequential frames, achieving 99.23% testing accuracy.
4. **EnviLens — Sustainable Product Analyzer** *(Google Competition & YouTube Demo)*
   - Sustainability app submitted to the Gemini API Developer Competition, integrating Google ML Kit barcode scanner with Gemini-driven conversational assistance.
5. **SafeHaven — AI & IoT Elderly Care System** *(Drive Demo & IEEE Award)*
   - Assistive healthcare solution with real-time fall detection, sensor telematics, and cross-platform desktop/mobile dashboards built with Python Flet and Supabase.
